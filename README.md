# Personal Portfolio Website

## Description
This is my personal portfolio website developed using HTML, CSS, and JavaScript. It showcases my skills, projects, education, and contact information in a responsive and modern design.

## Features
- Responsive design
- About Me section
- Skills section
- Projects showcase
- Timeline
- Contact form
- Smooth animations and interactive UI

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open `portfolio.html` in any web browser.
